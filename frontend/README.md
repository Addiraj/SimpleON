# SimpleOn Frontend

Decentralized 3x10 Matrix & Booster Plan Web Application built with React, TypeScript, Tailwind CSS, and Ethers.js.

## Requirements

- Node.js >= 18
- npm or yarn

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Key Features

- Web3 Wallet Connection (MetaMask, WalletConnect, Web3Modal)
- Interactive 3x10 Matrix Visualizer
- Booster Plan Activation & Upgrade Matrix
- Real-time Earnings Ledger & Transaction History
- EIP-712 / SIWE Cryptographic Wallet Sign-In
